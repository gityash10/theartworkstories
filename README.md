# The ArtWork Stories

The ArtWork Stories is a plain HTML, CSS, and JavaScript site exploring the stories behind human-made art.

## Structure

- `pages/` contains page entry documents, currently `pages/home/index.html`.
- `css/` contains base styles, reusable components, page styles, and animation utilities.
- `js/` contains shared core behavior and page-specific behavior.
- `assets/` contains images organized by purpose.
- `data/` contains artwork metadata modules.
- `docs/` contains the architecture and existing design-system notes.

## Run

Open `pages/home/index.html` in a browser, or serve the project directory with any static HTTP server. No build step or package installation is required.
